# ModelForge 模型模块重构原型

状态：`design-preview`。当前目录只用于预览和方案选型，生产模型页尚未修改。

## 打开预览

在项目根目录启动静态服务：

```powershell
python -m http.server 4312 --bind 127.0.0.1 --directory designs
```

打开：

```text
http://127.0.0.1:4312/modelforge-models-redesign/index.html#c
```

页面顶部可在 A / B / C 三套方案间切换，右侧可切换信息密度和明暗主题。

## 三个方案

| 方案 | 信息组织 | 适用场景 | 取舍 |
|---|---|---|---|
| A · 模型资产台 | 整体统计、模型家族目录、右侧固定版本检查器 | 日常检索、版本管理与批量运维 | 扫描效率最高，视觉辨识度相对克制 |
| B · 来源血缘账本 | 每个模型家族一条账本，来源、文本指纹、实例核对、兼容基线和 Adapter 关系展开在同一证据链 | 审计、复现与模型血缘追踪 | 来源关系最清楚，单行承载的信息较多 |
| C · 模型验证工作室 | 模型家族索引、证据工作台、训练准入与操作栏 | 判断模型能否进入训练、处理上传和兼容异常 | 信息最完整，也是当前推荐方案 |

C 把“文件已校验”和“可以训练”拆成不同门禁。来源快照、manifest SHA-256、实例文件核对、模型 / GPU / 镜像兼容和引用保护都有独立状态，不因对象可读而自动判定可训练。

## 已覆盖交互

- 模型家族与不可变版本选择，保留 `model_id`、版本 ID 和短码。
- 搜索名称或 ID，按来源、待处理、异常、兼容状态筛选。
- ModelScope、目录上传、优云公共基座三类来源的统一添加抽屉。
- 后台导入进度、当前文件、断点复用、取消和固定快照重试语义。
- 外部公共基座的“待实例核对”状态。
- MinIO 清理失败、引用删除保护、内容不一致等异常入口。
- 文件按 config、Tokenizer、权重和其他类别展开。
- Best / Final Adapter、来源 Attempt、数据集版本、验证 Loss 与同步状态。
- 模型族状态聚合全部版本，并组合呈现可用、传输中和异常状态。
- 每个可用 Adapter 显示基座模型、基座指纹、Adapter 指纹、数据集版本，以及固定的 `manifest.json`、`adapter_config.json`、`adapter_model.safetensors` 文件清单。
- BEST 与 FINAL 分别显示“下载 BEST Adapter 包”和“下载 FINAL Adapter 包”，并提供原型模拟的基座配对校验。
- 引用与训练产物只保留一个工作台 Tab 入口，右侧验证栏不再重复提供相同入口。
- 模型证据 Tab 支持方向键、Home、End、roving tab index 和重绘后的焦点恢复。
- 明暗主题、信息密度、键盘焦点和 reduced-motion。
- 390px 下优先显示当前模型、版本、状态和主操作，总览统计后移；模型族和版本选择提供横向滚动提示。
- 手机端证据链使用横向滑动，Best / Final 卡片改为单列，并提高功能文字和按钮尺寸。

## 2026-11-03 局部优化

本轮保留 C 版视觉基线，只修正 Adapter 契约、模型族聚合状态、移动端层级和可访问性。

- Adapter 演示数据与本地正式接口中的最新一组 Best / Final 元数据对齐。
- 390px 下工作台从约 965px 提前到 357px，上下文主操作从约 2561px 提前到 569px。
- Best / Final 在手机端从两张 167px 卡片改为两张 345px 全宽单列卡片。
- Adapter ID、契约文字和其他功能性小字提升到至少 11px，移动端主操作高度为 44px。
- 工作台三个 Tab 各自关联唯一 `tabpanel`，支持方向键、Home、End 和重绘后的焦点恢复。
- 页面级横向宽度在 390px 下保持 390px；Adapter 卡片内部也不再产生横向溢出。

- `review/final-verification-20261103.md`

验收时 Ego 窗口处于最小化状态，截图接口按安全策略拒绝执行；本轮没有恢复窗口或抢占桌面，因此保留原有参考截图，并使用 Ego DOM、无障碍结构、交互和多视口测量完成验收。修改后的可视截图仍是明确证据缺口，不用旧参考图替代。

## 文件

- `index.html`：原型入口。
- `styles.css`：三套布局、主题、响应式和交互样式。
- `app.js`：模型数据形态、三套视图、筛选、版本切换和添加抽屉。
- `review/`：历史参考截图、修改前后测量和跨方案审计。
- `review/baseline-metrics-20261103.json`：修改前桌面与手机测量。
- `review/cross-variant-final-audit-20261103.json`：A/B/C 与移动端最终审计。
- `review/final-verification-20261103.json`：最终 Ego DOM、响应式、键盘与无障碍证据。
- `review/final-verification-20261103.md`：最终验收结论和证据边界。

原型不调用模型 API，不写入 PostgreSQL 或 MinIO。正式实施仍需复用现有后端的模型版本、导入任务、外部基座登记和 Adapter 契约。
