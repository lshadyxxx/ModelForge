# AI 微调分析：原型与接入建议

状态：静态原型与接入规格，真实服务待实施。更新时间：2026-10-29（Asia/Shanghai）。用户已确认智能报告的分析模型使用 DeepSeek（DS）；具体模型版本、服务地址、部署方式和实施批次尚待确定。原型仍为本地演示，此选型不自动扩充已冻结的首版验收范围。

## 已确认的模型选择（2026-10-29）

- 用户确认：智能报告的分析模型使用 DeepSeek（DS）。这一选择用于报告分析，不改变训练任务中基础模型、GPU 和镜像的选择。
- 接入方案：后端独立配置分析服务地址、模型标识和凭据；凭据仅服务端保存。DeepSeek 品牌选择不等于已确认使用官方托管 API，也不代表已部署本地模型。
- 分析方案：程序从原始 step/epoch 指标计算最低有效验证 Loss、变化幅度和对应的已保存 Checkpoint；将带证据 ID 的数值、参数和脱敏日志摘要作为文本输入交给模型解释。页面曲线与报告使用同一份指标快照，无需把曲线截图作为首版分析的必需输入；图片输入作为后续扩展建议。
- 执行边界：报告服务独立于当前训练 Adapter，接入设计不默认占用训练 GPU；报告失败不阻断训练与实例回收。
- 当前进度：仅记录模型选择与接入方案，尚未配置凭据、调用模型服务或实现应用；应用开发仍按用户要求在动手前确认。

## 要回答的问题

让用户从一次 Task / Attempt 看懂当前发生了什么、结论依据在哪里、证据缺什么，以及下一次可以做什么可验证的实验。当前静态原型使用本地模板，未调用 AI；报告中的判断、日志、Loss 和实例全部来自演示数据。

入口：工作台“体验分析示例”，或训练详情“AI 分析”。直接示例为 `index.html?demo=analysis`。报告的证据按钮打开指标、只读运行控制台、输入快照或实例记录；建议先生成待审核的新任务草稿，用户仍需完成提交确认。

## 原型已实现的交互

- 生成、取消、更新报告；服务失败时可重试，上一份成功报告保留。
- 固定采集截止时间、Task / Attempt 身份和输入快照；新观测使报告过期，禁用改参草稿。
- 区分观察、可能原因和证据不足；Loss 回升只提示可能迹象，不能据此证明真实回答质量提升。
- 缺少指标时不给收敛结论；显存不足、产物回传失败、清理未确认、主动取消分别解释。
- 以参数差异确认生成下一次实验草稿；当前任务参数和 Attempt 保留。重试归档旧报告，旧 Attempt 可导出报告。
- Markdown 导出包含报告身份、证据完整度和参数/指标快照。
- 训练与推理控制台支持只读日志、身份/连接状态、搜索、来源筛选、暂停显示、自动跟随、下载及断线快照/重连演示。暂停显示不暂停任务。

## 建议的真实接入流程（待实施）

1. API 接收指定 Task / Attempt 的人工分析请求，后端固定证据快照和截止时间。训练继续执行。分析使用独立可配置的模型服务，不依赖当前微调 Adapter，也不默认占用训练 GPU。
2. 先由确定性代码计算点数、最低验证点、Best/Final 身份、退出阶段和文件可用性等事实；每条证据有稳定 ID 与来源。只把有界、脱敏后的摘要送给分析模型。
3. 模型按结构化报告契约返回解释与建议。后端校验 schema、数值、证据引用与参数白名单；无证据的断言不作为事实展示。日志和数据字段均视作输入材料，不作为可执行指令。
4. 页面显示报告、缺失证据与不确定性；引用跳转到实际指标区间或日志锚点。证据已更新则提示报告过期，保留旧快照。模型不可用、超时或输出不合法只影响报告，不阻断训练、取消、回传或清理。
5. 用户核对差异后创建新任务草稿，提交时仍经过兼容性、参数、库存、租约和输入校验。分析不自动执行命令、改参、停止训练、删除实例或发布产物。

采用既有 FastAPI API / 单 Worker 边界和 PostgreSQL 状态，无需引入 Redis 或新增编排平台。具体执行方式、超时和重试预算在实施票中决定。若确认持久化：建议 PostgreSQL 保存报告元数据/状态/引用，MinIO 保存正式报告及脱敏证据快照；本地只作暂存。该建议未构成已采纳架构决策。

## 建议的输入与输出契约

| 数据 | 内容与约束 |
|---|---|
| 身份 | report_id、Task / Attempt、snapshot_id、截止时间、schema/提示词/分析模型版本。 |
| 固定输入 | 基础模型内容指纹、数据版本与拆分身份、训练预设和实际参数。 |
| 已采集观测 | 带 step/epoch/时间及来源的训练/验证指标；日志摘要与锚点；进程退出、产物和清理事实。 |
| 缺失观测 | GPU 利用率/显存峰值、独立效果评测等未采集项必须明确，不推算成真实数据。 |
| 报告 | 当前判断、观察、可能原因、证据 ID、不确定性、缺失项、建议的单变量实验。 |
| 参数建议 | 当前值、候选值、理由、依据、影响；受控字段和范围校验，始终先生成草稿。 |

原始数据集样本、聊天内容、完整环境变量、云 API 密钥、SSH 凭据默认排除。真实发送外部服务前展示分析端点与待发送内容供用户核对；凭据仅后端配置。当前原型无设置页、凭据输入或外发请求。

## 仍需决定

- DeepSeek 的具体模型版本、服务端点和部署方式：官方托管、其他服务商或公司内网部署；实际可用性在接入时验证。
- 首版是否纳入真实 AI 分析，或作为完成训练闭环后的增量；本轮只交互探索。
- 除手动生成外是否自动触发；调用预算、超时、重试与失败提示。
- 报告/证据保留期限、历史查看和删除规则。
- GPU 监控来源、独立效果评测数据与“效果改善”的判定方法。

## 真实验收建议

同一事实必须能从实际数据库、指标或日志追溯；没有验证数据时不能生成验证结论。至少覆盖准备中、进行中、完成、显存错误、网络/存储错误、取消、旧报告过期、Attempt 切换、无效模型输出、服务超时/断开。确认建议不会自动操作云实例，导出与页面一致，外发内容遵循预览范围。真实 AI 可用不代表微调效果已提升，效果仍由独立试用/评测验证。
