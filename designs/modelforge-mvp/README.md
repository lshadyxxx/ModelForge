# ModelForge 连续流程交互原型

状态：`needs-review`（待用户审阅）。改版与浏览器检查：2026-10-28 至 2026-10-29，Asia/Shanghai。

本原型用于判断“创建一次训练后，是否能清楚走到产物选择、独立试用和实例回收”。六入口及产品边界沿用[产品规格](../../<internal-evidence>)；页面组织和视觉尚待审阅。

## 打开预览

在项目根目录运行：

```powershell
python -m http.server 4311 --bind 127.0.0.1 --directory designs
```

浏览器打开 `http://127.0.0.1:4311/modelforge-mvp/index.html`。若 4311 已有本项目静态服务，直接打开即可。停止预览时在启动终端按 Ctrl+C。无需构建或安装依赖。

当前入口：[连续流程](index.html)。旧稿：[A](legacy-variants.html?variant=A)、[B](legacy-variants.html?variant=B)、[C](legacy-variants.html?variant=C)，仅供对照。

## 体验一条完整路径

1. 在工作台点击“创建训练”；选择基础模型和已发布数据版本。公共基座标明“外部只读”，托管模型标明 MinIO。
2. 选择区域、单 GPU 配置和训练镜像。演示的“兼容性未知”镜像会阻止继续；GPU C 显示无库存。GPU A/B/C、显存和价格仅是样例，没有锁定真实验收型号。
3. 设置任务名、轮数、学习率、最大序列长度与验证比例；展开高级参数查看 Batch、梯度累积、LoRA、调度与随机种子。返回前一步会保留草稿。
4. 核对摘要和固定拆分（默认 240 条中的 216 训练 / 24 验证），确认后提交。创建向导、任务列表和任务详情各自独立。
5. 在详情查看阶段、指标、日志、输入快照、Attempt 历史与实例。阶段每两秒加速推进；训练成功退出、产物校验、实例释放分别展示。
6. 检查 Best / Final。演示按每个 epoch 验证并保存，Best 对应最低有效验证 Loss，Final 对应末次输出。模型入口的“训练产物”也能跳回对应任务。
7. 选择 Best 或 Final 试用，重新选择推理资源与镜像，创建独立实例。看到模型恢复、指纹核对、运行时加载和就绪检查等准备阶段后才能输入。
8. 发送两轮消息；可停止当前生成、继续追问或清空上下文。“停止生成”保留实例，“结束试用”进入删除与确认流程。
9. 手动结束，或者展开原型控制演示“无请求空闲 15 分钟”回收。再次试用创建新的实例身份，产物继续留在本页演示状态中。

## 体验 AI 分析与运行控制台

工作台点击“体验分析示例”，或直接打开 `http://127.0.0.1:4311/modelforge-mvp/index.html?demo=analysis`。该入口载入已完成的内置任务并生成模板报告；它不调用 AI 或申请云资源。

- 查看结论及依据，跳到验证点、输入快照或日志；导出 Markdown 报告。
- 生成调整草稿，确认参数差异后进入新任务参数页；原任务仍保留，尚未提交训练。
- 展开原型控制演示分析不可用；更新失败保留旧报告。任务新观测会提示过期，重试 Attempt 归档原报告。
- “运行控制台”可搜索、筛选来源、暂停显示、自动跟随、宽屏、下载和演示断线重连。推理页也有独立运行控制台。

接入方案与待定项见 [AI_ANALYSIS.md](AI_ANALYSIS.md)，实际检查见 [分析/控制台记录](review/analysis-verification-2026-10-29.md)。当前 AI 页面属于设计探索，不表示真实 AI 或新增首版验收已经完成。

## 体验其他入口

- 数据集：上传按钮使用内置有效/错误样例。错误样例显示物理行号、字段路径和原因，不能发布；有效样例发布后才能用于训练。被任务引用的版本保留删除保护。
- 模型：公共目录登记只读引用；目录上传、公开 ModelScope 和公开 Hugging Face 使用演示导入记录。按文件模拟中断恢复，复用已校验文件，重传失败文件。
- 计算环境：查看资源、镜像及平台创建的训练/推理实例，跳到关联记录。
- 训练列表：搜索、按运行/待处理/结束筛选，并打开对应 Task；失败重试增加 Attempt，保留固定输入和旧 Attempt。

## 异常恢复演示

相关页面底部的“原型控制”只用于审阅场景；正式产品不需要这些模拟按钮。

| 所在位置 | 场景 | 预期行为 |
|---|---|---|
| 资源选择 | 提交前库存变化 | 保留输入，阻止继续；刷新恢复或更换配置。 |
| 参数页 | 轮数填 0 等越界 | 留在参数页，显示错误及原生字段提示。 |
| 工作台 | MinIO 不可用 | 状态如实变红，发布/导入/提交等相关动作被阻止。 |
| 训练详情 | 训练执行失败 | 不发布部分 Adapter；模拟确认停止并删除实例，重试增加 Attempt。 |
| 训练详情 | 主动取消 | 显示停止核对中，确认退出与删除后释放 GPU。 |
| 训练详情 | 产物回传失败 | 保留持有唯一输出的实例；禁止试用，提供恢复回传。 |
| 训练详情 | 实例清理失败 | 产物已校验与 GPU 未释放同时存在；核对删除后才开放试用。 |
| 推理准备 | 基座指纹不一致 | 阻止进入对话，提供重新核对或结束回收。 |
| 推理试用 | 结束时删除失败 | 停止接收请求，保留实例身份与 GPU 占用；重试核对删除。 |
| 推理试用 | 无请求空闲 15 分钟 | 快进演示计时并回收；生成中不能按空闲回收。 |

## 文件与证据

- `index.html`、`flow.css`、`flow-data.js`、`flow-views.js`、`flow-insights.js`、`flow-app.js`：新版入口、样式、样例目录、页面和内存交互。
- `legacy-variants.html`、`styles.css`、`prototype.js`：保留的旧版 A/B/C。
- `_d_meta.json`：设计资产索引，状态保持待审阅。
- [浏览器检查记录](review/verification-2026-10-29.md)：实际覆盖、观察结果、截图和限制。

原型不会连接 PostgreSQL、MinIO、优云或真实模型；不读取本机模型目录、不上传用户文件。目录、价格、依赖状态、Loss、日志、实例和回复全部为演示。刷新/关闭会丢失所有演示任务、导入及聊天，原型不能证明真实持久化、后端计时、重启对账、训练效果或计费。下载只提供 DEMO 样例清单/日志，不伪造权重。
