## 实施顺序

1. 托管模型：不可变 manifest、完整目录按文件上传/恢复、MinIO 回读校验、取消及删除保护。
2. 公开仓库：ModelScope / Hugging Face 解析不可变 revision，后台下载，失败重试保持 revision。
3. 优云公共基座：外部只读登记、文件内容身份和执行前核对契约；远程探测由后续传输票接入。
4. 自动化测试、真实 PostgreSQL/MinIO 验收与三轴 host-only 审查。

## 契约

- 测试接点：models 对外用例、HTTP API、公开仓库 HTTP 边界；不运行模型仓库代码。
- 完整目录先提交相对路径、大小、SHA-256；同一路径内容改变必须新建版本，不能修改原 manifest。
- 上传单个文件使用临时文件缓冲，流式计算 SHA-256，正式对象只经 MinIO 保存。按文件恢复不包含单个文件分片续传。
- 文件在 MinIO 回读校验后记为 verified；所有必需文件和完整目录校验成功才标记 available。文件传输成功不代表训练/推理兼容。
- 外部只读引用不创建 MinIO 文件索引；登记不代表已经远程验证，也不允许客户端自行声明可训练。
- 容量限额保持可配置、未锁定；真实仓库/GPU/性能验证与自动化 fixture 证据分别记录。

## 已实现

- `0005_model_directory` 保存模型、不可变版本、文件 manifest、校验状态和引用。完整目录必须含 config、tokenizer、权重或有效分片索引。
- 按文件恢复；MinIO 完整回读核对大小、SHA-256 后才 verified，全部文件和结构通过才 available。`compatibility_state=unverified`，不表示模型可加载或训练。
- 取消后拒绝新上传，原 manifest 可恢复并复用已验证文件；删除先保护引用、确认对象消失，再清理元数据，失败保留 `delete_failed` 供重试。
- 状态查询不获取写锁；冲突写操作立即返回 `409 model_busy`，表示操作未接受、可稍后重试，不假称已经停止传输。
- 完整 MinIO object key 按 UTF-8 检查 1024 字节上限，含 96 字节固定前缀。Nginx 上传路由关闭请求缓冲，容量由 API 强制限制。
- 初始容量：20 GiB/文件、100 GiB/目录、10000 文件；limits API 返回配置版本及 `locked=false`，尚未用大模型传输锁定。
