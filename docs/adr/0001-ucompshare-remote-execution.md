# 首版通过优云接口支持远程训练与产物推理试用

用户明确要求通过优云智算获取服务器配置、运行镜像和公共模型，向云端传送数据集训练，并回收权重，支持在优云运行微调产物后于 ModelForge 内对话验证。因此产品首版纳入 UCloud 优云智算接入，替代此前将所有云 GPU 编排排除在首版之外的范围约定；单平台 Worker、单 GPU 的规模边界继续保留。

React、FastAPI、PostgreSQL、MinIO 和本地控制面 Compose 保持既定选型。远程执行带来的实例状态、任务状态、产物回传和断线恢复需分别管理，以换取无需依赖本机显存的真实训练能力；整套平台手动搬到云主机不覆盖用户要求的 API 工作流。其他云厂商、跨实例集群调度、多 Worker、Redis 和 Kubernetes 仍后置。

这是需求与架构范围决策。用户已进一步确认训练实例策略：用户选择单 GPU 规格和镜像，平台按训练 Attempt 创建实例；训练依赖预先创建实例不属于首版路径。

用户确认训练成功后先将必需产物写入并校验 MinIO、登记为可用版本，再释放训练实例；发起试用时创建独立 vLLM 推理实例。相较于保留训练实例直接对比，此选择需要额外的实例启动和模型准备时间，换取产物持久化与试用资源生命周期分开管理。训练实例释放确认前不再申请推理 GPU；回传/校验失败时保留唯一输出，清理失败时保留实例关联供重试。

用户进一步确认推理实例采用手动结束加空闲 15 分钟自动删除：无进行中的请求时由后端计时，关闭页面后仍生效，再次试用重新创建；正式模型产物保留。该方式增加持久化空闲期限和重启对账要求，避免资源生命周期依赖浏览器在线。

基础模型、GPU 规格和镜像通过真实目录查询后由用户在功能界面选择，不在规格阶段预设特定型号；实现阶段声明和验证支持范围，不能把目录可见当作任意组合可运行。

用户确认失败/取消训练不发布部分 Adapter，核实远程训练停止后删除实例，保留已取得日志并标记缺失；训练成功但必需产物同步失败继续保留实例以恢复回传。公共基础模型直读的存储例外见 [ADR-0002](0002-external-readonly-base-models.md)。具体执行通道仍在[产品 MVP 规格](../../<internal-evidence>)中收敛。[官方能力核对](../../<internal-evidence>)未证实托管微调或自有权重发布到 ModelVerse 的公开 API；不能据此承诺一站式托管接口。本轮不调用账号 API，不创建云资源，不执行部署。
