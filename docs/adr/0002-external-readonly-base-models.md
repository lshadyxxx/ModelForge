# 优云公共基础模型采用外部只读引用

2026-10-28 用户确认采用外部公共基座路径：训练与独立推理实例直接读取优云公共模型目录，不要求先将公共基础模型完整复制到 MinIO。这样避免公共权重经过本地控制面重复下载和上传；代价是平台无法保证外部文件永久存在，必须核对模型身份，不能把公共路径当作不可变版本。

这是原“所有正式模型文件进入 MinIO”的明确例外，仅适用于优云公共基础模型。PostgreSQL 保存来源、目录、配置、完整文件清单与内容指纹，训练启动前固化版本；独立推理和重试必须核对相同基座，缺失或指纹变化时阻止执行，不静默换模型。公共目录的实例类型、镜像与挂载兼容性须单独验证。

用户完整目录上传、ModelScope/Hugging Face 导入的模型，以及正式数据集、Best/Final Adapter 和需保留的训练产物继续保存到 MinIO；本地临时目录与云实例工作区都不成为正式存储的替代方案。外部基座不提供平台资产文件下载或删除源文件能力，后续若需独立归档，再明确新增复制入库流程。详细契约见[产品规格](../../<internal-evidence>)。
